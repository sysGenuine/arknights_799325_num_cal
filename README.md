# 799325 数字论证器

把**任意数字**，用 `7 9 9 3 2 5` 这一串数字，只通过 `+ − × ÷` 与括号表示出来。
灵感与架构来自 [itorr/homo（恶臭数字论证器）](https://github.com/itorr/homo)。

## 打开

双击 `index.html` 即可（纯静态、无外链、离线可用）。输入数字即时出结果：

```
2024    = (7−99)×(3−25)
123456  = 79×9×32×5+79×(9+3)×2×5+7+(9+93)×2+5
3.14    = (7−(9+9−325))÷((7+993)÷(2×5))
```

## 规则

1. 六个数字必须**按 7 → 9 → 9 → 3 → 2 → 5 的顺序**出现；
2. 相邻数字可以拼接成 `79`、`799`、`799325` …；
3. 只用 `+` `-` `×` `÷` 和括号；
4. 一串不够时，**整串可以按顺序重复使用**（大多数数字会复用 1~10 次，页面会标注复用块数）。

> 只用一次这六个数字、只用四则运算时，能精确得到的整数其实只有 2,524 个（0~100 全覆盖），
> 「任意数字」必须靠第 4 条——这也是 homo 的做法。

## 原理

1. **枚举单串值**：对 `799325` 的每个连续子串做区间 DP（BigInt 分数，精确无浮点误差），
   合并加减乘除，得到一串数字能表示的全部值——共 9,684 个有理数，其中 1,660 个非负整数。
2. **贪心分解**：对目标 N，取 ≤ N 的最大可表示块 v，令 `N = v × 商 + 余数`，对商和余数递归；
   余数始终 < v，因此必然收敛，且很快就会落到 0~100 的稠密区间。
3. **美化**：把全括号中缀串解析成 AST，按运算符优先级重新打印，去掉多余括号。

## 校验

```bash
node verify.js          # 全量 33,586 项，全部通过 exit 0
node verify.js --quick  # 900 项冒烟
```

覆盖 −2000..2000 全量、0..200000 步长 7、1000 个随机 9 位数、负数与小数；
每条都要求"表达式的值精确等于输入"且"数字串匹配 ^(799325)+$"。
